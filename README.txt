Snake 3D - Android source project

This is a native Android OpenGL ES 2.0 3D snake game project. It includes a perspective camera, 3D spheres for the snake and food, a tiled 3D floor, touch direction controls, score and restart.

Build an installable APK using GitHub Actions:
1. Create a GitHub repository and upload all contents of this folder.
2. Open the repository's Actions tab.
3. Select "Build Snake 3D APK" and press "Run workflow".
4. When complete, open the run and download the "Snake3D-debug-apk" artifact.
5. Extract app-debug.apk on your Android phone and install it. You may need to allow installation from that file manager.

Note: This ZIP is source code, not an APK. The head is a basic 3D human-like game character, not a photorealistic likeness. The game is fully 3D rendered with OpenGL ES.
